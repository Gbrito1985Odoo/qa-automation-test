# Convención de evidencias

- Nombre: `<ID>_<paso>_<timestamp>.png` (por ejemplo `WEB-01_inventory_20261127-103000.png`).
- Almacenamiento: adjuntos en GitHub Issues/Projects o carpeta `evidencias/` con Git LFS si se solicita.
- Tamaño máximo: 2 MB por archivo.
- `docs/manual/evidencias/` está excluida de Git por peso; este README es el índice de referencia.
- Cada caso manual indica la evidencia mínima requerida en su sección "Evidencia requerida".
